# Web Dev I - Lab Assignment 3: Responsive Personal Portfolio Website

## Lab Description
This project is an advanced, responsive single-page personal portfolio website built using modern CSS features. It features a structured layout covering a Header, Hero, About, Skills, Projects, Contact, and Footer section[cite: 2].

## Technologies Used
- HTML5 (Semantic elements)
- CSS3 (Flexbox, CSS Grid, Media Queries, Keyframe Animations, Transitions)
- Google Fonts (Inter)

## Steps to View Responsive Behavior & Breakpoints Tested
1. Open `index.html` in any modern web browser (Google Chrome, Firefox, Edge).
2. Right-click anywhere on the page and select **Inspect** to open Developer Tools.
3. Toggle the Device Toolbar (Ctrl+Shift+M or Cmd+Shift+M).
4. Test across the following custom media query breakpoints:
   - **Desktop View (> 768px):** Displays side-by-side hero layout (text left, profile image right) and multi-column grid layouts for skills and projects[cite: 2].
   - **Tablet & Mobile View (<= 768px):** Automatically collapses layouts into single-column stacking (hero text stacks above image, navigation centers vertically, and grids reflow seamlessly)[cite: 2, 4].
